# Inputs

`regions.json` holds the source data for the collage:

- `shapes` — the same simplified, stylized region polygons used by the maze
  material (Montréal/Québec stands in as a maple leaf).
- `layout` — per-region `dx`/`dy`/`scale` placement on the shared canvas.
  Positions are a loose south-to-north arrangement for a road-trip feel, not
  a geographically accurate projection.
- `labels` — display name printed under each outline.
