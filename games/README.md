# Games

Each subfolder is one standalone road-trip bingo game.

- `<game-slug>/index.html` — the playable board (open directly in a browser).
- `<game-slug>/inputs/` — the board content as data, separate from the
  rendering code, for reviewing/editing before changes are folded back into
  `index.html`.

## Current games

- `billboard-bingo-md-nj-de-ny-montreal/` — MD · NJ · DE · NY · Montréal road
  trip, billboards/chains/road signs.
